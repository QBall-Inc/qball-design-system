Display container · image / gif / video / embed

1 · Media types

The discriminated type prop selects the inner element — one component, four render paths. image/gif → <img>, video → <video poster> (native controls; default muted, no autoplay), embed → a facade (real provider thumbnail + a real play button on a dark scrim; the iframe loads only on click — no network/cookies until then).

2 · Shapes

Shape mask at the frame level — the inner media fills it (overflow:hidden). Reuses the existing radii vocabulary (--radius-md) and the circle/pill idiom already shipped on Avatar/Badge. mask takes an arbitrary clip-path for anything beyond these four.

3 · Fit & position

A wide source in a square frame, to show object-fit. cover fills + crops (default), contain letterboxes, fill stretches. position chooses which part of a cover crop shows.

4 · Aspect ratio (CLS-safe)

aspect-ratio reserves the box before media loads — no layout shift. Portrait, square, and landscape from the same component.

9 / 16 portrait
1 / 1 square

5 · Empty state & placeholder

No src → .media-slot--empty. Placeholder content scales with the box (container-query units), so a bigger slot ⇒ bigger glyph/label. Three treatments: the passive default ("no media"), an icon-only avatar empty, and the active drag-and-drop / upload dropzone (the latter is the authoring-layer visual, shown here for reference — display-only consumers use the passive ones).

6 · Facade play overlay (states)

Now on a dark scrim (token --color-scrim) so it reads on any thumbnail — the earlier translucent-sage hover blended into a sage image. Rest = scrim; hover = solid sage (opaque, no blend); keyboard focus = sage ring. The glyph is light (theme-independent, on the scrim). Button size scales with the slot.

7 · Fluid / responsive

The slot is fluid by default: it fills its container's width and the height follows from aspect-ratio (the fixed widths above are just for this contact sheet). The consumer controls the width — a grid cell, a max-width, 100%, or a fixed px. Resize the window to watch this one reflow (and the placeholder glyph scale with it).
