Tool-use / skill indicator — state matrix

The lifecycle chip for a skill / tool call in the terminal transcript (e.g. news-research, sec-filings-lookup). Sage leads (running); finance caution (partial) always pairs its color with a glyph + the word "partial". No shadows, no emoji, radius 4px. Toggle light/dark above — every state is token-driven.
