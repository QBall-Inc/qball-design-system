# QBall Design System — Logo Assets

Faceted low-poly sphere mark ("the ball"), grounded in the QBall palette:
dark outline · sage primary mesh · amber secondary depth.

## Notes
- Dark variants use a sage outline so the silhouette reads on charcoal (a near-black outline would otherwise disappear there).
- Transparent GIF uses binary alpha (no partial transparency), so the faint amber depth layer drops out — it reads as a sage + dark wireframe. Parchment/dark GIFs keep the full amber.
- README header recommendation: `qball-logo-transparent.png` (or `-dark.png` if the README renders on a dark theme).
