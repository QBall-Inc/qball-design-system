GraphCanvas: the QuBrain 3D knowledge-graph canvas in `./graph` (`GraphCanvas.mount(host, { data })`). Data-only, three.js loaded lazily as an optional peer (`>=0.186.0 <0.187.0`), seeded or precomputed layout, select / expand / filter / setData / destroy, typed `select`/`clear`/`filter`/`retry`/`error` events, overridable `labels`, scoped Esc with `suppressKeys`, typed `GraphCanvasError` failures, render pausing while hidden, and the `GRAPH_CANVAS_MARKER` build marker. See docs/graph-canvas.md.
